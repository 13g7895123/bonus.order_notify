# 使用者詳細資料查看功能說明

## 功能簡介

在管理者的「使用者管理」頁面中，新增了查看每個使用者底下各項資料的功能。管理員可以點擊使用者卡片上的「眼睛」圖示，開啟詳細資料視窗，查看該使用者的完整資料。

## 使用方式

### 1. 開啟詳細資料視窗

1. 登入管理員帳號
2. 進入「使用者管理」頁面
3. 在任一使用者卡片的右上角，點擊「眼睛」圖示 (👁️)
4. 詳細資料視窗會以模態視窗的形式彈出

### 2. 查看統計概覽

視窗頂部會顯示該使用者的統計資料，包含：
- **客戶數量**：該使用者建立的客戶總數
- **範本數量**：該使用者建立的訊息範本總數
- **本月訊息**：該使用者本月發送的訊息數量
- **LINE 使用者**：與該使用者 LINE Bot 互動的使用者數量
- **活動日誌**：該使用者的 API 操作記錄總數

### 3. 切換資料類型

視窗中間有 5 個按鈕，可以切換不同的資料類型：

#### 📋 客戶
顯示該使用者的所有客戶資料，包含：
- 客戶名稱
- LINE UID
- 建立時間

#### 📄 範本
顯示該使用者建立的所有訊息範本，包含：
- 範本名稱
- 範本內容
- 建立時間

#### 💬 訊息記錄
顯示該使用者發送的所有訊息，包含：
- 接收客戶名稱
- 訊息內容
- 發送者類型（系統/使用者）
- 發送時間

#### 👥 LINE 使用者
顯示與該使用者 LINE Bot 互動的所有使用者，包含：
- 顯示名稱
- LINE UID
- 首次互動時間

#### 📊 活動日誌
顯示該使用者的所有 API 操作記錄，包含：
- HTTP 方法（GET/POST/PUT/DELETE）
- API 端點
- 回應碼（成功顯示綠色，失敗顯示紅色）
- IP 位址
- 操作時間

### 4. 分頁瀏覽

當資料超過 10 筆時，視窗底部會顯示分頁控制：
- 顯示當前頁碼和總筆數
- 「上一頁」和「下一頁」按鈕
- 第一頁時「上一頁」按鈕會被停用
- 最後一頁時「下一頁」按鈕會被停用

### 5. 關閉視窗

點擊視窗右上角的「X」按鈕即可關閉詳細資料視窗。

## 技術特點

### 效能優化
- 採用分頁載入，避免一次載入過多資料
- 切換資料類型時自動重置為第一頁
- 僅在需要時才向後端請求資料

### 使用者體驗
- 模態視窗設計，不需離開當前頁面
- 統計資料以彩色卡片呈現，一目了然
- 資料類型切換按鈕有明確的選中狀態
- 提供載入中和空資料的友善提示
- 所有時間都以台灣時區格式顯示

### 安全性
- 僅管理員可以存取此功能
- 後端會驗證使用者權限
- 使用 JWT Token 進行身份驗證

## API 端點

```
GET /api/users/:id/details?type=customers&page=1&limit=10
```

### 參數說明
- `id`: 使用者 ID（路徑參數）
- `type`: 資料類型（查詢參數）
  - `customers`: 客戶
  - `templates`: 範本
  - `messages`: 訊息記錄
  - `line_users`: LINE 使用者
  - `activity_logs`: 活動日誌
- `page`: 頁碼（預設 1）
- `limit`: 每頁筆數（預設 10）

### 回應格式
```json
{
  "user": {
    "id": 1,
    "username": "admin",
    "name": "管理員",
    ...
  },
  "stats": {
    "customers": 10,
    "templates": 5,
    "messages_total": 100,
    "messages_this_month": 20,
    "line_users": 8,
    "activity_logs": 150
  },
  "data": [...],
  "total": 10,
  "page": 1,
  "limit": 10,
  "type": "customers"
}
```

## 常見問題

### Q: 為什麼看不到「眼睛」圖示？
A: 此功能僅對管理員開放，請確認您是以管理員身份登入。

### Q: 資料會即時更新嗎？
A: 資料在開啟視窗時載入，若需要最新資料，請關閉後重新開啟視窗。

### Q: 可以匯出這些資料嗎？
A: 目前版本尚未提供匯出功能，此功能已列入未來開發計劃。

### Q: 為什麼有些資料顯示「未命名」？
A: 這表示該筆資料在建立時沒有設定名稱欄位。
