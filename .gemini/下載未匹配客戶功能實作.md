# 下載未匹配客戶 Excel 功能實作總結

## 📋 功能概述

當使用者匯入 Excel 檔案進行客戶匹配時，如果有無法匹配的客戶名稱，現在可以直接下載一個包含這些未匹配客戶的 Excel 檔案，格式與原始檔案相同。

## 🔧 實作內容

### 1. 後端實作

#### 檔案：`backend/app/Controllers/Api/Notifications.php`

**新增方法：`downloadNotFoundCustomers()`**
- **功能**：生成並下載包含未匹配客戶的 Excel 檔案
- **輸入**：
  - `headers`：原始 Excel 的欄位標題陣列
  - `not_found`：未匹配的客戶名稱陣列
- **處理流程**：
  1. 驗證使用者身份
  2. 驗證必要資料（headers 和 not_found）
  3. 使用 PhpSpreadsheet 創建新的 Excel 檔案
  4. 設定標題列（第一列），並套用樣式（粗體、灰色背景）
  5. 從第二列開始填入未匹配的客戶名稱
  6. 自動調整欄位寬度
  7. 設定下載 headers 並輸出檔案
- **檔名格式**：`未匹配客戶_YmdHis.xlsx`（例如：未匹配客戶_20260121220000.xlsx）

#### 檔案：`backend/app/Config/Routes.php`

**新增路由：**
```php
$routes->post('notifications/download-not-found', 'Notifications::downloadNotFoundCustomers');
```

### 2. 前端實作

#### 檔案：`frontend/src/services/api.js`

**新增 API 方法：`notifications.downloadNotFound()`**
- **功能**：呼叫後端 API 並觸發瀏覽器下載
- **參數**：
  - `headers`：欄位標題陣列
  - `notFoundNames`：未匹配的客戶名稱陣列
- **處理流程**：
  1. 發送 POST 請求到 `/api/notifications/download-not-found`
  2. 從 Response Headers 的 `Content-Disposition` 取得檔名
  3. 將 Response 轉換為 Blob
  4. 創建臨時 URL 並觸發下載
  5. 清理臨時資源

#### 檔案：`frontend/src/pages/SendNotification.jsx`

**修改內容：**

1. **新增 Icon 匯入**：
   ```jsx
   import { ..., Download } from 'lucide-react';
   ```

2. **新增狀態**：
   ```jsx
   const [downloading, setDownloading] = useState(false);
   ```

3. **新增處理函數**：
   ```jsx
   const handleDownloadNotFound = async () => {
       if (!importData?.not_found || importData.not_found.length === 0) {
           return;
       }
       setDownloading(true);
       try {
           await api.notifications.downloadNotFound(importData.headers, importData.not_found);
       } catch (e) {
           alert('下載失敗，請稍後再試');
       } finally {
           setDownloading(false);
       }
   };
   ```

4. **UI 更新**：
   - 在「找不到以下自定義名稱」區域的標題列右側新增下載按鈕
   - 按鈕樣式：次要按鈕（secondary）、小尺寸（sm）
   - 按鈕文字：「下載 Excel」（下載中時顯示「下載中...」）
   - 按鈕圖示：Download icon

## 📊 使用流程

1. 使用者點擊「匯入 XLS」按鈕上傳 Excel 檔案
2. 系統處理並顯示匯入結果
3. 如果有未匹配的客戶（not_found.length > 0）：
   - 顯示未匹配客戶的名稱列表
   - 顯示「下載 Excel」按鈕
4. 使用者點擊「下載 Excel」按鈕
5. 系統生成包含未匹配客戶的 Excel 檔案
6. 瀏覽器自動下載檔案

## 🎨 UI 設計

**下載按鈕位置：**
```
┌─────────────────────────────────────────────────┐
│ ⚠️ 找不到以下自定義名稱 (共 X 筆)：  [📥 下載 Excel] │
├─────────────────────────────────────────────────┤
│ 客戶A, 客戶B, 客戶C...                           │
└─────────────────────────────────────────────────┘
```

**按鈕特性：**
- 位置：與警告訊息同一列，右側對齊
- 樣式：次要按鈕（灰色系）
- 尺寸：小型（與警告文字協調）
- 狀態：下載中時禁用並顯示「下載中...」

## 📝 生成的 Excel 格式

**範例：**

| 客戶名稱 | 獎金金額 | 發放日期 |
|---------|---------|---------|
| 王小明   |         |         |
| 李小華   |         |         |
| 張小美   |         |         |

- **第一列**：欄位標題（粗體、灰色背景）
- **第二列起**：未匹配的客戶名稱（僅填入第一欄）
- **其他欄位**：保留空白，供使用者補充資料後重新匯入

## 🔍 技術細節

### 後端技術
- **函式庫**：PhpSpreadsheet
- **檔案格式**：XLSX (Excel 2007+)
- **編碼**：UTF-8
- **樣式**：標題列粗體 + 灰色背景 (ARGB: FFE0E0E0)
- **欄位寬度**：自動調整

### 前端技術
- **下載方式**：Blob URL + 臨時 `<a>` 元素
- **檔名取得**：從 Content-Disposition header 解析
- **錯誤處理**：try-catch + alert 提示
- **資源清理**：下載後立即釋放 Blob URL
